# 合并第一阶段：整理来源并确定结构

使用本次用途、目标和明确的来源范围。读取 [核心风格](core-style.md)、[合并指导](document-merging.md)、[依据](evidence.md)、[概念解释](concepts.md)、[组织指导](organization.md) 及相关 [正反例](examples-and-counterexamples.md)。学习或复盘文档读 [学习笔记](learning-notes.md)，方案读 [方案指导](proposals.md)。

## 实际工作与产物

完整阅读本次要合并的来源，理解各文档的主要内容、条件和判断。指定只合并选定章节时按明确范围读取，并补足判断依赖需要的上下文。记录来源与当前版本或状态。

处理重复、互补、术语差异、版本和结论冲突：将互补内容整理成完整解释，重复内容确定保留方式，版本差异回到任务和依据判断；无法解决且影响结论的冲突具体询问。方案中的候选与已确认设计按方案指导区分。

在产物中写出处理后的关键内容与必要说明、来源对应和具体取舍，按目标用途确定统一主线及内容安排。核心风格在当前产物中落实到概念、对象、因果和判断边界；原文作为来源，不在此阶段堆入未经整理的全文。

需要重新组织或绘制图时读 [图文指导](visuals.md)，保存实际图稿及其作用。早期产物聚焦内容整合和组织决定，完整合并稿在下一阶段形成。

## 完成条件

各来源的重要内容都有明确处理，主要重复与差异已解决或保留真实边界；必要概念解释可用；合并结构对应具体内容并满足本次用途，能引导下一阶段成文。

落盘后按 [结构检查](artifact-checks.md) 执行 `--flow merge --through 1`。通过后才读 [合并第二阶段](merge-2-draft.md)。
