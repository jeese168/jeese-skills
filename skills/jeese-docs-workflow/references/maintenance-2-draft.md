# 维护第二阶段：形成修订稿

使用有效修改安排、已经写出的解释、相关原文和本次要求。读取 [成文指导](drafting.md) 与 [组织指导](organization.md)，沿用 [维护指导](document-maintenance.md)。图受影响或需要新增时读 [图文指导](visuals.md)。

## 实际工作与产物

写出实际修订后的段落、章节或全文，同时处理必要的衔接、合并和连带变化。局部新增放到自然位置，覆盖部分已有解释时合成一次完整论述。整体重组按授权范围重新安排内容，仍保留有效主张。

修订稿标明对应原文位置，包含足以理解变化的前后关系；新解释、过渡和图稿达到可用程度。修订内容按本次影响范围保存到阶段草稿区，独立稿件按 [产物约定](artifact-checks.md) 管理。

发现影响范围或事实判断变化，更新第一阶段；重要方案选择按方案指导处理。长期文档的补充自然融入，临时记录保持必要时间线与来源。

## 完成条件

修订稿已完成本次要求的实际表达和必要连带修改；新增概念、因果及图文清楚；与原文的接续成立，原有主张按要求保留或有依据地更新。

落盘后执行 `--flow maintenance --through 2`。通过后才读 [维护第三阶段](maintenance-3-delivery.md)。
