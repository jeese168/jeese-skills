# 多篇文档合并

用于用户明确将多篇独立文档合成一篇。按本次用途、读者和理解或实施目标确定合并方式，保留来源依据。

长期维护文档重新选择统一主线，把各来源当成材料，处理重复、术语差异和冲突判断。临时汇总可以保留来源边界和材料顺序，通过必要说明建立关系。编辑策略从任务和上下文判断。

相同主题的两段内容先判断是否互补、重复、版本不同或结论冲突；互补内容形成完整解释，重复内容保留一次，版本差异依据当前任务处理。无法确认的冲突和不确定事实保留边界；影响最终结论且无法自行解决时，说明实际差异并询问。

早期产物保留经过取舍和解释的内容、来源对应及组织决定，完整合并稿在下一阶段形成。合并后核对各来源的重要主张、条件和必要内容是否得到合适处理。

章节、比较表和具体表达按实际材料及本次用途决定。
