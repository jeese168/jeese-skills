# 学习第四阶段：核对并修订成稿

使用最新完整初稿、有效内容与组织安排，以及本次目标和层次。读取 [交付指导](delivery.md)，核对所需的核心风格与格式要求。

从读者角度连续通读：正文是否支撑本次理解目标，概念是否在首次需要时讲清，机制与条件是否相连，各部分为什么接着出现。对照依据修正事实与引用，对照组织安排处理遗漏、重复与无关展开，核对图文和可读性。

修订正文并同步受影响的前阶段产物，按交付指导写入正式文档、检查实际结果。在第四阶段记录交付位置、实际检查及剩余边界。

完成条件：文档在本次范围内完整且可独立阅读；事实、解释、图与引用一致；目标文件及其资源可用。写入阶段记录并执行 `--flow learning --through 4`，通过后交付文档链接和必要说明。
