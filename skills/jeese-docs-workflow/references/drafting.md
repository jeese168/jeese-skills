# 使用前阶段内容成文

取得本阶段依赖的有效内容和组织安排后，读取 [核心风格](core-style.md)、[正反例](examples-and-counterexamples.md)，创建或重组 Markdown 时读取 [格式指导](markdown-format.md)。已在上下文中的完整有效指导可以复用。

按照已经形成的内容与组织安排写出正文，自然改写、衔接和展开。正式文档遵循任务和项目约定，个人学习文档使用适用的写作默认值。

先写完整论述再精修句子。首次使用的概念解释到足以支撑下文，对象、行为与条件明确。连续思想由段落承载，实际并列、步骤和比较使用相应结构。口语承担解释或推理功能，正式方案适当降低口语浓度。

图文按照组织安排配合：图展示关系、顺序或变化，正文交代意义、原因、条件与判断。图中对象在附近有足够说明；关键定义进入正文，不只留在工作记录。

写作中发现解释或依据缺口，修正对应阶段产物再继续；设计发生变化时按方案指导处理。已有记录提供实际内容，当前风格指导仍约束本轮表达。

完整初稿在新文档第三阶段或合并第二阶段形成；维护第二阶段按实际影响范围形成修订稿。默认草稿正文放在当前阶段区块，需要独立编辑较长稿件时按 [产物约定](artifact-checks.md) 保存关联草稿。目标正式文档在最后阶段写入。
