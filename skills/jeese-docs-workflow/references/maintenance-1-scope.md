# 维护第一阶段：确定修改内容与影响范围

使用本次要求、目标文档与相关材料，读取 [核心风格](core-style.md)、[维护指导](document-maintenance.md)、[依据](evidence.md)、[概念解释](concepts.md) 和相关 [正反例](examples-and-counterexamples.md)。学习或复盘文档读 [学习笔记](learning-notes.md)，技术方案读 [方案指导](proposals.md)。

## 实际工作与产物

读到足以判断本次修改及后续依赖的原文范围，整体重组时完整阅读目标。记录当前文件状态或相关原文位置，作为最终写回前核对的依据。

判断新内容承担什么作用、自然归属在哪里、哪些主张需要保留，以及哪些概念、结论、过渡、引用或图受到影响。明确表达调整与判断变化。发生冲突先核对，无法解决或必要修改超出授权范围时具体询问。

在产物中写出加工后的新增解释、判断修正、必要依据和对应修改安排。核心风格中当前可核对的概念、对象、因果和表达要求当场落实；原文作为来源按需读取，不把整份原文副本当作本阶段成果。

## 完成条件

修改目的、内容归属和直接影响明确；新增的关键解释已可用；保留与改变的判断清楚；必要冲突或范围问题已有处理。产物能够具体引导下一步修订。

落盘后按 [结构检查](artifact-checks.md) 执行 `--flow maintenance --through 1`。通过后才读 [维护第二阶段](maintenance-2-draft.md)。
