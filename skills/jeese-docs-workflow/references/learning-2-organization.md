# 学习第二阶段：确定文章主线与组织

使用本次要求和第一阶段的有效解释与依据，缺失或变化的内容按 [补读约定](artifact-checks.md) 取得。读取 [组织指导](organization.md) 与 [Markdown 指导](markdown-format.md)，结合 [学习笔记](learning-notes.md) 选择适合主题的推进方式。需要图时读 [图文指导](visuals.md)。

## 实际工作与产物

围绕本次目标选择一条主线，安排具体内容的阅读顺序：共同前提在哪里建立，局部概念首次在哪里使用，机制、例子与边界怎样相连。标题服从真实语义层级及项目约定。

记录对应实际内容的组织安排。关键衔接写出可用文字，合并重复解释，取舍不影响本次目标的旁支。需要视觉呈现时形成实际图稿及配套说明，写清它帮助理解什么、放在哪里。

此阶段使用前面已经写出的解释。若发现某概念尚未解释够用，回第一阶段补足；仅位置不合适则在当前阶段调整。必要解释安排进正文，不以读者曾看过工作附录为前提。

## 完成条件

全文主线可说明，各部分接续有具体关系；前提先于依赖它的内容；关键概念在使用位置可被理解；图、例子和正文各有作用。安排已能引导下一阶段成文，不能只剩通用章节名称。

落盘后执行 `--flow learning --through 2`；修订第一阶段时也核对其完成条件并检查。通过后才读 [学习第三阶段](learning-3-draft.md)。
