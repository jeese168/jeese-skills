# 学习第一阶段：准备内容与依据

使用有效任务记录、本次学习目标和抽象层次。读取 [核心风格](core-style.md)、[学习笔记](learning-notes.md)、[依据](evidence.md)、[概念解释](concepts.md) 和 [正反例](examples-and-counterexamples.md) 中适用的指导，完整有效内容已在上下文时复用。

## 实际工作与产物

从讨论、资料、代码探索和已有讲解中整理当前有效的认识。核对影响本文的关键事实，保留必要来源、条件和未确认部分。已有解释适合本次目标就直接采用；本次范围不同则补足或收缩。

把必要概念、对象关系、机制和例子写清，按概念指导递归补足会阻断理解的前提。主问题达到选定层次，相邻内容说明到足以理解作用。复盘按学习笔记指导分开实现、观测、判断和未来改进。

在当前阶段记录实际加工后的内容与依据。按内容选择连续段落、关系表或过程说明，不要求原始材料在工作文件里再复制一遍。核心风格中当前已经可检查的对象身份、概念含义、因果条件、判断边界和段落完整性，在落盘前修正。

## 完成条件

本次主要理解目标已有足够的有效内容支撑；关键概念和必要前提已有实际解释；关系、条件和结果连得起来；依据及未知边界清楚。必要缺口继续补，事实变化核对后更新说明。产物长短以本次范围为准。

完成落盘，按 [结构检查](artifact-checks.md) 执行 `--flow learning --through 1`。通过后才读 [学习第二阶段](learning-2-organization.md)。
