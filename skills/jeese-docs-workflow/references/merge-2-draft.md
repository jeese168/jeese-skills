# 合并第二阶段：形成合并初稿

使用第一阶段处理后的内容、取舍、来源关系、组织安排与图稿，缺失或变化的部分按 [产物约定](artifact-checks.md) 补读。读取 [成文指导](drafting.md)，沿用 [合并指导](document-merging.md)。

## 实际工作与产物

根据已经确定的合并结构写出完整文档。共同前提集中交代，必要概念在首次使用处解释，重复内容合并，段落和章节沿统一主线推进。用户需要临时汇总时，保留来源边界和顺序并建立必要联系。

正文保留来源中决定含义的条件，实际依据、判断与设计状态清楚。图文一起处理，不能因来源使用不同术语而在合并稿中留下不一致对象。

完整初稿保存到当前阶段草稿区。写作中发现新的内容冲突、概念缺口或组织问题，更新第一阶段再继续；独立草稿按产物约定管理。

## 完成条件

合并初稿已覆盖选定内容，关键解释与上下文成立；来源差异按已确定方式处理，正文没有机械拼接和重复结论；可以对照来源进行整篇核对。

落盘后执行 `--flow merge --through 2`。通过后才读 [合并第三阶段](merge-3-delivery.md)。
