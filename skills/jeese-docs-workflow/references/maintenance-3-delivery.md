# 维护第三阶段：写回并核对全文关系

使用最新修订稿、修改安排、当前原文和必要依据。读取 [交付指导](delivery.md)，按 [维护指导](document-maintenance.md) 核对本次结果。

写回前确认目标文档是否有新增改动，将变化纳入当前判断并处理冲突。先核对修订稿与原文关系，再按授权范围更新正式文档。

查看实际差异并通读受影响的完整上下文，核对前提、概念、结论、标题、编号、引用、图及后续依赖。涉及全文主线的修改通读全文，局部修改检查其实际依赖范围。发现问题修正文档和受影响的工作产物。

完成条件：本次修改已准确写回，相关解释和全文关系成立，必要链接与图资源可用，无关修改得到保留。第三阶段记录交付位置、重要结构或判断变化和实际核对结果，执行 `--flow maintenance --through 3` 后交付。
