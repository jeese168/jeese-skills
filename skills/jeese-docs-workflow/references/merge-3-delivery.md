# 合并第三阶段：核对并修订成稿

使用最新完整初稿、来源对应、取舍和必要依据。读取 [交付指导](delivery.md)，按 [合并指导](document-merging.md) 核对合并结果。

对照来源检查重要主张、条件和必要内容是否得到合适处理，是否改变原意或掩盖冲突。来源发生变化时先更新对应内容。连续通读检查统一主线、概念位置、衔接、重复和图文一致性。

修正正文及受影响的前阶段产物，按约定写入合并目标并核对实际文件和资源。来源保留供回查，目标替换范围遵循任务授权。

完成条件：合并结果保留本次需要的内容和真实边界，整篇符合目标用途且可读，目标文件及其引用正确。第三阶段记录来源处理与交付的实际结果，执行 `--flow merge --through 3` 后交付。
