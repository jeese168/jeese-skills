# 技术方案第四阶段：核对并修订成稿

使用最新完整初稿、有效需求与现状、已确认设计及其依据和图稿。读取 [交付指导](delivery.md)，应用 [方案指导](proposals.md) 核对实施完整性。

对照本次需求检查遗漏和范围，核对方案与实际实现、项目约定及已确认决定是否一致。检查跨模块协作、依赖、关键条件和验证安排能否支持本次实施；新概念、改法的作用与理由是否真实、足够清楚。

连续通读正文，修正各节之间断裂、重复总结和图文不一致。发现设计变化时回对应阶段处理，再同步草稿。按交付指导写入正式目标，核对实际文件、差异、链接与图资产。

完成条件：本次范围内的方案可理解、可据以开展工作，实际依据与设计边界清楚；正式文件及资源正确。第四阶段记录交付和实际检查状态，执行 `--flow proposal --through 4` 后交付。状态说明指向方案文档，不把项目实施标为已完成。
