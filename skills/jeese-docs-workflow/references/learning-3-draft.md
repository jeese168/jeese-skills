# 学习第三阶段：形成完整初稿

使用前两阶段中本文需要的最新解释、依据、组织安排和图稿；缺失时按 [产物约定](artifact-checks.md) 补读。读取 [成文指导](drafting.md)，按其中路由使用核心风格、正反例和格式指导。

## 实际工作与产物

按已经形成的主线写出完整学习文档，把概念、因果、例子和边界在自然位置连起来。文章应当独立可读，所需前提进入正文。复盘的认识变化呈现为证据、对比和修正后的判断，不照录问答过程。

使用已有图稿，配套文字解释图中的关键概念、意义与条件。完整初稿保存到当前阶段草稿区，独立草稿文件的使用遵循产物约定。

段落与整体组织一起检查：发现事实或概念缺口，更新第一阶段；发现顺序和衔接问题，更新第二阶段。相应产物有效后继续写作。

## 完成条件

全文已覆盖本次目标并保持选定层次；前阶段的实际内容与组织决定落实到正文；必要解释、图文和引用可用；没有需要读者自行拼接的关键断层。初稿足以供整篇核对。

落盘后执行 `--flow learning --through 3`。通过后才读 [学习第四阶段](learning-4-delivery.md)。
