# 多文档合并

这份 reference 目前只保留已经明确的边界，等待真实合并任务继续校准。仅在用户明确要求把多篇独立文档合成一篇时使用，不从普通编辑任务推断合并需求。

开始前判断目标文档是长期维护还是临时汇总，并确认读者、用途和主要理解目标。现有信息不足且不同选择会改变合并方式时，主动询问。

- 长期维护文档需要重新选择统一主线，把各来源当成材料，处理重复、术语差异和相互冲突的判断，不能按原文件顺序直接拼接。
- 临时汇总可以保留来源边界和材料顺序，通过少量说明建立关系，不必为了形成完整文章而抹掉原始痕迹。

无法确认的冲突、来源差异和不确定事实必须保留边界，不擅自选择一个版本，也不为了连贯而补造中间内容。

当前没有足够真实案例，不预设固定合并流程、章节模板或正反例。以后根据实际合并结果补充，而不是提前穷举规则。
