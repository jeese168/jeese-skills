# 插画提示词与 FIG

配图服务于文章的具体段落。按内容选择有价值的位置和数量，交付可直接用于生图的完整提示词、图位与图注，不调用生图工具。收到现成图片后核对画面与正文对应，再按真实路径接入。

## 选择场景与视觉表达

优先用具体生活场景、人物动作、物件和空间关系表达文章中的意思。正文可以尖锐，配图仍可平静；图像通过分担、距离、朝向、停留或离开等动作让读者感受关系。

通用画风：日系生活杂志随文插画，轻二次元人物处理，生活物件和环境有可信细节；低饱和、偏明亮的米白、暖灰、浅棕，按场景加入少量灰绿或灰蓝；柔和自然光，纸张颗粒、轻彩铅线条和水彩质感。

人物以侧面、背面、低头或中远景呈现，五官简略，表情克制，主要通过姿态与关系传达状态。通用关系题材弱化没有信息作用的性别特征；具体身份和人物特征按本次题材需要决定。

关系和社会观察可以保留较充实的生活空间；自省或学习感想可以使用更淡的彩铅效果、留白、物件或局部动作。横向 4:3 是可用的常见起点，画幅按正文位置和用户要求确定。画风描述采用可观察特征。

## 写出完整提示词

每张图单独交付完整描述，让用户可以直接复制：场景与关键主体，谁做什么、处于怎样的关系，空间安排与构图，画面应传达的状态，再写色彩、光线、材质和人物处理。需要保留的局部限制直接写在该图提示词中。

通用画风要在每条独立提示词中落实。根据本图场景和用户要求写出具体限制，保留原始需求中已明确且与该图相关的“不要文字”“不强调人物性别”等要求。

示例仅示范写法：

> 横向 4:3，两名年轻人在明亮的房间里收拾书本和纸箱，一人低头认真整理，另一人坐在旁边稍作休息。场景平静自然，通过物件分布和动作呈现分担的差异。日系生活杂志式轻二次元插画，米白、暖灰、浅棕与少量灰绿色，柔和自然光，彩铅线条、水彩晕染和纸张颗粒。中景构图，人物以侧面和低头姿态呈现，五官极简、表情克制，服饰和体态不过度强调性别，画面不含文字。

## FIG 的表达

FIG 是与画面相连的一句作者表达，承接正文的观察或判断。按画面和论述需要，选择简短场景提示后接具体意思，或直接写一句贴合画面的判断。

| 本次需要 | 写法 |
| --- | --- |
| 点破矛盾、锋芒鲜明 | 直接说明行为、关系或反差，保留本次已明确的判断力度 |
| 留出余味、表达含蓄 | 以具体动作和关系承载意思，完整分析留在正文 |
| 自省或认识变化 | 接近当时的发现、变化或行动愿望，用自然语气落到本篇主题 |

同一整理房间的画面，可以明确写“事情一起发生，分担却未必一样”，也可以更含蓄地写“房间慢慢空下来，留下的东西却不止纸箱”。第二句只有确实符合本篇意思时才采用，不为含蓄而另加作者没有表达的情绪。

图注不是绘图指令，正文中的 `FIG. …` 与 HTML 的 `figcaption` 保持同一句话。标题、FIG 和正文力度协调；用户要求微调某一处时，具体调整那一处。

样本图注：

> FIG. 整理旧物：人在重新理解一段关系的时候，也会重新挑选那些能够支持自己现在判断的过去。

短场景提示接一个与正文相关的判断，按本篇需要选择锋芒或留白。

## 提示词交付与已有图片

任务目录中使用 `illustrations.md`，逐张写图位标识、正文位置、图意、完整提示词、FIG 和建议文件名。来源素材存在时说明如何参考；文件名建议不等于图片已经存在。

第三阶段同步最终标题、段落与图注。实体图默认放在正文同目录的 `文档图片/`，保留实际文件名及正确扩展名。按用户要求只交付提示词时，明确图像待接入；需要导出且图片尚未提供时，按打印指导处理。

## 正文中的图位与引用

实体图片引用采用目标项目约定。使用 Obsidian 的项目可以采用 `![[文档图片/文件名.png]]`，其他环境优先标准 Markdown 相对图片路径及有信息量的 alt。转换 HTML 时将相对路径改成从 HTML 位置可访问的地址。

图片或待配图位置下一段写 `FIG. …`，图注用一句具体意思呼应正文，可有简短场景引导。其表达力度与本次文章一致。FIG 的表达按本文件前述判断。

尚未收到图片时，用任务内稳定标识保留位置，例如：

```markdown
<!-- illustration: scene-1 -->

FIG. 收拾房间：事情一起发生，分担却未必一样。
```

提示词文件以同一标识对应，不把生图指令混入正文。已有图片接入后，用实际图片引用替换位置注释。用户只要文章或提示词时，这种图位状态可正常交付，并明确图片尚未接入。
