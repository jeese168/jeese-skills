# 随笔的共同风格

先理解用户这次想说什么，再组织文章。由作者承担取舍和连接的工作，让读者沿正文就能理解判断怎样形成。以下规则应用于当前产物，后续成文继续使用。

## 原意与依据

输入可以是聊天记录、其他 AI 的中立复述、分点整理或已有文章。先辨认哪些意思由用户提出、认可或修正，哪些只是模型建议、第三方引文或未接受的解释。本次明确要求优先；需要保留的态度、例子和措辞进入实际产物。

### 把作者意图保留下来

复述材料语气中立，不代表成稿要中和作者立场。条目化草稿的编号也不代表用户选择了同样的文章结构。找出这些形式下面的主张与关系，再按文章重新组织。

具体输入已能确定的内容直接处理；含混之处会改变主张时，用材料中的实际分歧询问。没有原始聊天时，根据现有材料能够支持的内容写，不编造用户曾说过什么，也不要求为了开始写作必须补齐完整聊天。

个人经历、身份和感受以用户本次提供的材料为依据。样本帮助判断写法，不证明其中社会、历史或心理判断适用于当前对象。

### 核对影响论述的事实

区分可核实事实、用户观察、推断和价值判断。涉及具体新闻、数据、历史事件、引文或会变化的信息时，按可用能力核对适当来源。保留会影响含义的条件，引用和链接落在实际支持的内容附近。

证据足以支持的判断直接写，语气与依据相称。存在具体事实错误时修正对应论据；改变主张需要用户决定时说明实际冲突。不能为迎合主张补造证据，也不能以一般性的谨慎措辞稀释已经成立的论述。

### 现实判断的权重

没有个案证据时，以常见模式、基准率、主要机制和已有证据为起点。具体而有力的事实可以改变一般判断。不同解释按证据强度、现实可能性和与本题的关系分配篇幅，证据偏向一方时明确表达。

例外进入主线，应当因为它并不罕见、会改变结论或选择、有本次具体依据、后果严重值得处理，或正是文章要回答的内容。其他理论可能性保留必要边界即可。

分清发生概率、后果严重程度和是否值得行动。无法可靠量化时使用与依据相称的表述，保留真正有意义的未知；条件和未知表达清楚以后，文章仍然可以有鲜明态度。

## 从由来进入文章

文章通常有一个引子：事情、观察、知识、经历或长期积累的认识。材料给出具体经过时，可以从具体事情讲起；用户概括带过时，以相应程度交代由来。开头建立本篇思考的起点，然后自然进入主线。涉及个人经历、身份和感受，只使用用户实际提供的内容。

用户希望记录认识变化时，保留有意义的时间推进和发现过程；材料中零散的追问、试探结构与重复纠正，则整理为稳定的论述。时间线是否保留取决于它是否承担文章内容。

自省表达的新示例：

> 那天我把整理好的笔记重新打开，才发现很多句子只是当时抄下来的。我认得每个词，却已经说不清它们为什么连在一起。原来保存下来和真正理解，中间还隔着一步。

这段从事情进入，认识随着观察形成。例子中的经历属于示意，实际文章使用用户提供的事情。

## 连续论述与必要解释

一段承担一个主要任务，相邻段之间有因果、条件、转折、顺序或例证关系。相关思想用连续自然段展开，段落长短随内容变化。重要短句可以独立成段，形成转折、停顿或落点。真正并列、步骤或比较才使用列表、编号和表格。

新概念在第一次需要时解释到足以支撑后文。定义、作用、机制与当前关系属于同一理解单元时，在所属位置讲清；必要前提逐层补到本次文章够用的位置。对象、动作、条件和结果明确，尤其要让读者知道一句判断针对什么行为或关系。

把原因、过程、例子与后果连起来。同一判断通常解释一次，后文提供新证据或进入新的理解层次时再展开。已经形成的认识和置信程度随证据保持稳定。

结尾落在文章真正形成的认识、态度或行动上。已经说清的结论不再逐章重述。清理无信息开场、装饰性栏目、碎片化编号、空洞评价和只为完整而添加的旁支。

## 按情境选择声音

| 情境 | 对应表达 |
| --- | --- |
| 批判行为、观念或关系模式 | 用平实语言展开事实与机制，在论述推进到的位置直接判断，保留讽刺、尖锐比喻和攻击性短句 |
| 由事情引出的自省与思考 | 用自然坦诚的第一人称，沿经历、疑问、发现和认识变化推进，保留真实的犹豫与自我审视 |
| 同篇文章中的情绪变化 | 根据段落作用调整语气，让说明、反省和批判自然衔接 |

默认沿用本次输入的表达倾向。用户已有的强烈措辞是语义的一部分，不惯性替换成模糊的“有待改善”“不够成熟”。口语承担降低抽象、推动推理或表达判断的作用；措辞与内容一起决定力度。

样本先解释一方怎样反复抢回心理上的上位，随后写：

> 不要把每一次具体冲突都变成一次重新争皇位。

“争皇位”把关系中的荒谬感直接表达出来。改成“双方需要改善沟通方式”会改变原判断；改成全篇连续怒斥，则丢掉逐步解释形成的节奏。

## 比喻、模拟话语与节奏

比喻应映射具体关系：谁处于什么位置、动作怎样改变关系、矛盾在哪里。它可以同时带来理解和讽刺。优先保留材料中贴合主线的鲜明比喻；新增比喻也要能说清对应关系，之后自然回到论述。

“心理账本”对应亏欠与注销，“被告席和审判者”对应谁定义、谁解释。如果只写“关系像一座桥，需要双方维护”，却没有解释对应关系，读者仍需自己猜测。

人物可能说的话或内心逻辑，可以帮助读者看到行为怎样发生。示意话语与真实引文保持区别，不把自己写出的模拟话语当成用户或他人的实际原话。

例如样本中的模拟话语：

> 我不能有错。我是洁白无瑕的。我有充足的证据。判死刑。

短句让读者听到正在被分析的心理逻辑；它们是示意表达，不冒充某个人实际说过的话。

平实分析可以积累内容，再以短而强的判断收束；也可以先提出判断再展开。强句的位置取决于内容推进。

## 标题与引言

正文结构由实际内容和本次要求决定。已有文章的标题层级与段落组织有用时沿用，重组时按意义调整。打印样板提供字形和纸面样式。

一篇文章使用一个 `#` 篇名。大部需要聚合多组内容时用 `##`，节级内容可用 `###`；没有大部时可以直接使用节标题。短文也可以主要依靠段落推进。标题是路标或判断，按本篇语气选择简短主题名、具体陈述或确有内容的问题。

“合理化”“给予之后”可以作为定位主题的短标题；“别总想着应付过去”直接表达态度。标题不必都扩成长结论。

新文章沿用样本的标题区：篇名、`随笔 · …` 分类、独立的一段引言，再进入正文。分类自然概括主题，引言从用户的事情、观察或概括性的由来进入，不编造个人经历。修改已有文章时，是否补齐标题区由本次范围和目标约定决定；仅导出时缺少必要分类或引言，可根据原文拟定，在保持正文的同时对齐源 Markdown。

## Markdown 与强调

标题、段落、图、表及代码之间保留一个空行，清理粘贴造成的重复和多余空白。

适当加粗关键判断、重要转折、反差或决定性条件。短概念和有分量的句子都可以强调，重要判断也可以整句加粗并独立成段；避免整段都变成同一强度，让读者能够辨认落点。标题本身使用 Markdown 标题，不再外套加粗。正式 HTML 以 `strong` 保留强调，少数独立判断可按打印指导使用 `p.pull`。

列表、表格、引用和代码用于确实具有相应结构的内容。输入中的问答编号、机械栏目和聊天衔接语，在成文时根据实际关系重组；相关出处和会改变含义的条件保留。

## 样本与校准边界

用户明确确认的偏好包括作者立场、适用的攻击性和比喻、平实叙述后的强句、自省的自然推进、文章由来、适当加粗，以及标题和 FIG 的力度。上述短例用于把握表达，不作为当前社会或心理事实的证据。

成品观察以《防御与回应》为主，《别总想着应付过去》和《互联网中男性意识的变化与现代性价值的汇合》提供题材对照：连续段落展开关系，短句与判断形成落点，模拟话语呈现心理逻辑，时间线有时承担认识变化。未来按真实文章修改继续校准，题材要求留在适用情境。
